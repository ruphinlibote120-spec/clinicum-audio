# Clinicum — audios

Dépôt réservé aux fichiers audio de lecture des sujets médicaux de l'application Clinicum.
Il ne contient aucun dossier patient, aucun secret et aucun code de l'application.

Contenu indicatif, à vérifier avant tout usage clinique.

## Animations anatomiques (dossier `animations/`)

Vidéos MP4 pédagogiques (720×1280, 20 images/s) des signes, manœuvres et réflexes du dictionnaire médical de Clinicum.
`animations/index.json` liste les vidéos publiées (identifiant, terme, taille, durée, statut). L'application les télécharge à la demande et les conserve sur le téléphone.
Aucun dossier patient, aucun secret, aucun code de l'application. Schémas pédagogiques : à valider médicalement avant tout usage clinique.
